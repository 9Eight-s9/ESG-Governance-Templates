What this estimate means

Only documented, complete rows enter the subtotal. Excluded and incomplete rows are shown separately. This is a planning estimate; it does not measure water use, pollution, biodiversity or every consumption impact. Flight estimates need a compatible aviation methodology.

No per-person allocation or annualisation is performed automatically. Explain any manual allocation in the boundary notes.

How to use this tool

Carbon Calculator

Define your boundary, document factors, and estimate household emissions.

Estimated kg CO₂e = activity quantity × documented factor in kg CO₂e per matching unit. Divide by 1,000 for tonnes. No numeric factors are preloaded. Incomplete sources remain missing, not zero. This is a planning estimate; document uncertainty, allocation, scope, period and omissions.

Saving, backups & privacy

This is an independent static tool. Entries are stored only in this browser, under a tool-specific key. Other tools’ records are not changed. Export JSON for a restorable backup; CSV is a readable report. Imports are validated and require confirmation before replacing this tool’s entries. You can import an earlier combined-toolkit backup: only this tool’s relevant section is used.

Data are not uploaded. Browser storage may be unavailable or cleared; export a backup before closing when saving is unavailable. Store commitments and evidence without unnecessary personal details. This tool does not monitor or rank others.
